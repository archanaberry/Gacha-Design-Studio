📚 Contoh & Dokumentasi

🎯 Quick Start

// Buka window dasar
const winId = openWindow({
  title: 'Gacha Design Studio',
  content: '<p>Halo! (ketutup jika klik diluar window)</p>',
  footer: '<button class="footer-btn">OK</button>'
});

// Alert cepat
openWindowAlert('Pesan penting!', '⚠️ Peringatan');

// Tutup semua window
closeAllWindows();

🔧 API Examples

// Modifikasi window yang sudah terbuka
windowTitle(winId, 'Judul Baru');
continueWindowTitle(winId, ' - Subtitle');
contentWindow(winId, '<h3>Konten Baru</h3>');
footerWindow(winId, '<button class="footer-btn">Save</button>');
lockWindow(winId, true);
downWindowContrast(winId, 0.7);
stayWindowFocus(winId, true);
setTheme(winId, 'dark');

✨ Fitur Utama

  • 🔢
    Random ID Generation
    Setiap window mendapat ID unik dengan token bertumbuh
  • 🪟
    Multiple Window Support
    Buka banyak window tanpa batas, masing-masing independen
  • 🎯
    Close-on-Outside
    Klik di luar window untuk menutup (dapat di-toggle)
  • 🧲
    Drag & Resize
    Drag header untuk pindah, resize di pojok kanan bawah
  • 🎨
    Full Customization
    Header, content, footer dapat dikustomisasi sepenuhnya
  • 💾
    LocalStorage Support
    Simpan posisi & ukuran window otomatis
  • 📱
    Touch & Mobile Support
    Responsif dan mendukung interaksi touch
  • ⚡
    Event System
    Callback untuk onOpen, onClose, onBeforeClose
