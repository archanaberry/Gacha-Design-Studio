- Global properties (posX, posY, rotation, scale, opacity, color, etc)
- Per-src properties (posX0-9, posY0-9, opacity0-9, color0-9, etc)
- Property precedence (Per-Src > Global > Default)
- Optional properties
- Backward compatibility
- Text shape support
