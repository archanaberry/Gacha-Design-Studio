HOW IT WORKS NOW:
-----------------

1. Layer is created with options:
   {
     "color0": "#1A1A1A",
     "color1": "#FFFFFF",
     "opacity0": 1,
     "opacity1": 0.85
   }

2. Constructor calls #parseSrcProperties(options)
   → Parses color0, color1, opacity0, opacity1 into #srcProperties

3. For each src, #getColorForSrc(index) is called:
   → Returns #srcProperties[0]['color'] = "#1A1A1A" for src0
   → Returns #srcProperties[1]['color'] = "#FFFFFF" for src1

4. SVG is fetched and color is applied
   → fetch('hair1.svg')
   → Replace fill/stroke attributes with "#1A1A1A"
   → Create data URL with modified SVG

5. Console logs confirm:
   [Layer: Rambut] Applying color #1A1A1A to SVG src0
   [Layer: Rambut] Applying color #FFFFFF to SVG src1

6. IMG elements display recolored SVGs
   ✓ Visual: SVG colors visible in panel1
   ✓ DOM: img.src-item has data:image/svg+xml;base64,... URL
