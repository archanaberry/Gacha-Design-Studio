🔄 PROPERTY PRECEDENCE (Prioritas)
═══════════════════════════════════════════════════════════════════════════════

Per-Src Value > Global Value > Default

Contoh:
  "options": {
    "posX": 100,        // Global baseline untuk semua src
    "posX0": 150,       // src0 → pakai 150 (override global)
    "posX1": 120,       // src1 → pakai 120 (override global)
    "posX2": undefined, // src2 → pakai 100 (pakai global)
  }
