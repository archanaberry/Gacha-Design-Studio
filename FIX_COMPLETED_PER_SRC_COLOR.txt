✅ FIX COMPLETE - Per-Src SVG Color Properties
================================================

PROBLEM IDENTIFIED:
-------------------
User reported: "masih tetap ga berubah warna svg nya di src0 src1 src2 seterusnya"

ROOT CAUSE:
-----------
3 issues in layer.js preventing per-src colors from working:

1. #parseSrcProperties() didn't parse 'color' property
   └─ Only parsed: posX, posY, opacity, rotation, scale, skewX, skewY, flipX, flipY, width, height
   
2. #getColorForSrc() didn't check #srcProperties for color
   └─ Only checked: #srcColors (old) and this.#color (global)
   └─ So color0, color1, color2 from #parseSrcProperties never used
   
3. SVG fetch condition too strict: if (src.endsWith('.svg') && colorForThis)
   └─ Wouldn't fetch SVG if no color available
   └─ Prevented SVG loading even with other per-src properties

FILES MODIFIED:
----------------
✅ js/studiocharacter/layer.js

  Line 127: Added 'color' to srcPropertyNames in #parseSrcProperties()
  Before: ['posX', 'posY', 'opacity', 'rotation', 'scale', 'skewX', 'skewY', 'flipX', 'flipY', 'width', 'height']
  After:  ['posX', 'posY', 'opacity', 'rotation', 'scale', 'skewX', 'skewY', 'flipX', 'flipY', 'width', 'height', 'color']
  
  Line 169: Updated #getColorForSrc() precedence logic
  Before: Check #srcColors first, then global color
  After:  Check #srcProperties['color'] FIRST, then #srcColors, then global color
  
  Line 254: Changed SVG fetch condition
  Before: if (src.endsWith('.svg') && colorForThis) { fetch }
  After:  if (src.endsWith('.svg')) { fetch and apply color if available }

NEW BEHAVIOR:
--------------
When you define in studiopose.js:

{
  "layerName": "Rambut",
  "src": ["hair1.svg", "hairl1.svg", "hairss1.svg", "hairs1.svg", "hairo1.svg"],
  "options": {
    "color0": "#1A1A1A",
    "color1": "#FFFFFF",
    "color2": "#B39DDB",
    "color3": "#6A4C93",
    "color4": "#9C6FB1"
  }
}

Layer will now:
1. Parse color0-4 into #srcProperties[i]['color']
2. For each src, call #getColorForSrc(index) which returns the per-src color
3. Fetch SVG for each src
4. Apply the appropriate color to each SVG
5. Log: [Layer: Rambut] Applying color #1A1A1A to SVG src0
        [Layer: Rambut] Applying color #FFFFFF to SVG src1
        ... etc

CONSOLE OUTPUT:
---------------
Open browser console (F12) and look for:

✓ [Layer: Rambut] Applying color #6A4C93 to SVG src3
✓ [Layer: Rambut] Applying color #9C6FB1 to SVG src4

If you see these logs → colors are being applied ✅
