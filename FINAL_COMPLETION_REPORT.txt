🎯 FITUR SEKARANG SUPPORT
═══════════════════════════════════════════════════════════════════════════════

✅ GLOBAL PROPERTIES (Applies to all src)
   - posX, posY                    (Position)
   - rotation, scale               (Transformasi)
   - skewX, skewY                  (Skew)
   - flipX, flipY                  (Flip)
   - opacity, color                (Styling)
   - width, height                 (Size)

✅ PER-SRC PROPERTIES (Override global per src)
   - posX0-9, posY0-9              (Individual src position)
   - rotation0-9, scale0-9         (Individual transform)
   - skewX0-9, skewY0-9            (Individual skew)
   - flipX0-9, flipY0-9            (Individual flip)
   - opacity0-9, color0-9          (Individual styling)
   - width0-9, height0-9           (Individual size)

✅ PROPERTY PRECEDENCE
   Per-Src Value > Global Value > Default Value

✅ OPTIONAL PROPERTIES
   - Hanya define yang perlu
   - Undefined properties pakai default

✅ BACKWARD COMPATIBILITY
   - Format lama 100% supported
   - Global properties tetap work
   - Color per-src tetap work
